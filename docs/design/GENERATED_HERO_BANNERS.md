# Generated storefront hero assets — demo review

These images were generated with Codex's built-in image-generation tool for a local Kleawip design preview. They are not the source product catalogue photos. The product types and fabric textures were guided by Kleawip reference imagery; all headlines, offers, buttons, and links are rendered as editable website content over the images. No offer shown here is active.

## Prompt set

Use case: product-mockup / ecommerce hero photography. Create premium, photorealistic microfiber product imagery matching Kleawip's relevant fabric type. Leave generous negative space for separate HTML copy, with restrained Kleawip-blue or neutral backdrops, natural textile detail, clean lighting, no words, no logos, no prices, no watermark, and no competitor branding.

- Automotive drying towel: plush folded microfiber towels on a dark charcoal-blue studio surface, with the fabric pile clearly visible.
- Bath towel: soft folded microfiber bath towels in a calm, bright, blue-tinted bathroom/studio setting.
- Cleaning mitts: microfiber washing mitts/gloves with visible chenille-style pile against a clean neutral backdrop.

Each subject has separately composed desktop, tablet, and mobile crops rather than relying on one image stretched across all devices.
