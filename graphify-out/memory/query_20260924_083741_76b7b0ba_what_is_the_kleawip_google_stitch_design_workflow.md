# Q: What is the Kleawip Google Stitch design workflow?

## Answer

Use Google Stitch for customer and admin UI first-pass designs, then have the client review and approve before local implementation. Read docs/design/STITCH_MCP_FOR_KLEAWIP.md before design work. Build mobile-first, use Kleawip brand and own product assets, avoid invented prices or claims, generate grouped screens from one design system, and test each approved group. Never store or repeat Stitch API keys in project docs, code, logs, screenshots, or Graphify. User must enter fresh credentials in local Codex config; do not use exposed keys.
