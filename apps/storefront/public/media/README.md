# Product reel preview

`kleawip-twisted-loop-reel.m4v` is a local demo copy of the [official Kleawip Instagram reel](https://www.instagram.com/reel/DY96no4NaFh/) for the 1200 GSM Twisted Loop cloth. It was converted to an H.264/AAC, 720p web-friendly file on 25 September 2026. It is not a customer review.

Before production use, the client must confirm permission to host the video and its soundtrack outside Instagram. Replace this demo asset through the approved product-media workflow once that backend is ready. Do not use an expiring Instagram CDN URL as the site's media source.
